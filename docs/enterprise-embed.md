# 示范线AI智能助手：企业网页接入

## 接入步骤

1. 在网站管理界面发布当前版本，并按企业访问范围设置可访问性。取得已发布的 HTTPS 域名。仅有开发预览时，外部访客不一定能访问。
2. 在企业网页的公共模板中，将下面代码放在 `</body>` 前；将域名替换为助手实际的已发布域名。全站统一的页脚或页面模板通常只需添加一次。

```html
<script defer src="https://助手实际域名/embed.js"></script>
```

3. 保存并发布企业网页，打开页面，检查右下角入口、展开和收起、提问及参考来源。在手机上也检查是否遮挡页面内容。单页应用通常把这段代码放在全站 HTML 模板中，而不是在每次路由切换时重复插入。

脚本会在企业页面创建透明的独立 iframe，并从同一助手域名加载 `/widget`。对话请求在 iframe 内发往助手服务端，不需要把模型密钥放到企业网页。脚本只向企业页面发送面板展开状态，不向页面脚本转发对话内容。对话仅保存在页面运行内存中，刷新后清空。

本机知识库只在 Windows 电脑本机运行的服务中可用；云端发布的页面无法访问访问者电脑的 `D:\示范线知识库`。Windows 本机服务为保护本机资料仅监听本机，并禁止 iframe 嵌入，因此不能直接嵌入其他企业网页。云端页面找不到本机资料时需要使用者明确同意，才发送当前问题给配置的外部模型。

## 上线前检查

- 企业网页使用 HTTPS 时，助手也需要使用 HTTPS；如配置内容安全策略（CSP），请允许助手域名出现在 `script-src` 和 `frame-src` 中，并确认助手端允许企业网页作为嵌入来源。实际配置由企业安全团队审核。
- 当前公开问答接口尚未配置企业级身份认证、服务端访问控制或限流。公开部署后其他人也可能访问接口并消耗 AI 服务额度；上线前应按企业要求补充服务端鉴权、限流和监控，不能仅靠前端隐藏入口或限制嵌入域名。
- 助手处理访客输入和检索内容。上线前请审查隐私告知、数据分级、使用记录及企业政策，不要在未评估的情况下输入敏感生产数据。
- 当前问答流程优先检索 Windows 本机资料；云端无法访问本机知识库。尚未连接现场传感器、PLC、SCADA 或真实报警系统。现场实时数据和预警需要另行对接数据接口、权限及点位定义。
