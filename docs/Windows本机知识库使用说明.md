# Windows 本机知识库使用说明

## 1. 更新程序，保留旧文件

这次更新需要在**您的 Windows 电脑**上完成；GitHub 上的代码和云端预览不能直接读取您电脑的 D 盘。建议将新版下载或克隆到一个**新的程序文件夹**，不要覆盖原来的程序文件夹。原目录可能有您自行修改的代码和 `.env` 密钥配置；请先保留备份。知识库文件保存在 D 盘，程序本身和依赖安装在您选择的程序文件夹中，不一定在 D 盘。

下载方式任选一种：

- 在 GitHub 仓库 `https://github.com/ebvlihongyuan/demo-line-ai-assistant` 点击 **Code → Download ZIP**，解压到新的文件夹。
- 如果已安装 Git，可在 PowerShell 中进入准备存放程序的目录，再运行：

```powershell
git clone https://github.com/ebvlihongyuan/demo-line-ai-assistant.git lumichat-local-new
cd lumichat-local-new
```

如果您选择直接更新旧 Git 工作目录，请先运行 `git status --short` 检查本地改动，并备份 `.env` 及改过的文件；不要使用 `git reset --hard`、强制覆盖等命令。确认本地变更已妥善保留后，再按 Git 的提示处理更新。

## 2. 检查并安装运行环境

建议安装 Node.js 22，打开 **PowerShell**，进入新版程序文件夹，运行：

```powershell
node -v
npm -v
pnpm -v
```

如果提示找不到 pnpm，可以运行以下命令安装指定版本，再重新打开 PowerShell：

```powershell
npm install -g pnpm@10.18.0
```

进入新版程序文件夹后执行：

```powershell
pnpm install --frozen-lockfile
pnpm build
```

如果提示找不到 `package.json`，说明当前不在新版程序文件夹；用 `cd "实际文件夹路径"` 进入解压或克隆后的文件夹，再执行上面的命令。`node_modules` 和构建输出会写入该程序文件夹；只有知识库文件固定放在 D 盘。

如果 PowerShell 提示不允许运行 `pnpm.ps1`，可将命令中的 `pnpm` 改为 `pnpm.cmd`，例如 `pnpm.cmd install --frozen-lockfile`、`pnpm.cmd build` 和 `pnpm.cmd start`；无需修改系统执行策略。

## 3. 配置 DeepSeek（可选）

只有您希望在没有本机匹配时授权调用 DeepSeek，才需要配置 API。您可以从旧程序文件夹复制自己的 `.env` 到新版程序文件夹，**不要把密钥发到聊天或提交到 GitHub**。也可以在新版程序文件夹打开 PowerShell，运行：

```powershell
notepad .env
```

填写并保存（把示例密钥换成您自己的真实密钥）：

```dotenv
MANUS_API_URL=https://api.deepseek.com
MANUS_API_KEY=在这里填写您的DeepSeek密钥
MANUS_API_MODEL=deepseek-flash
MANUS_API_PROVIDER=deepseek
PORT=3000
```

请确认文件名是 `.env`，而不是 Windows 隐藏扩展名导致的 `.env.txt`。

如果端口 3000 已被占用，修改 `PORT` 为例如 `3100`，保存后重启程序，并在浏览器中使用对应端口。官方 DeepSeek 模型名及地址可能调整，配置以 [DeepSeek 官方快速开始](https://api-docs.deepseek.com/) 为准。API 密钥属于敏感信息；启用外部模型可能产生供应商费用。如果不配置 API，本机检索仍可使用，外部模型请求会提示配置错误。

## 4. 启动和访问

在新版程序目录运行：

```powershell
pnpm start
```

保持窗口运行，在**同一台电脑**的浏览器打开：

```text
http://127.0.0.1:3000
```

如果上一步改用了 3100，地址改为 `http://127.0.0.1:3100`。按 `Ctrl+C` 可停止服务。Windows 版只监听本机回环地址，不能用它直接向其他电脑提供本机知识库；为了防止其他网页嵌入本机页面诱导操作，本机模式也不允许嵌入 iframe。已有云端嵌入页面不因此获得访问您电脑 D 盘的能力。

Windows 启动窗口会显示一串随机的 **本机访问码**。首次打开页面时，请将启动窗口中的访问码复制到页面并点击“进入助手”。访问码不要分享给其他人；程序每次重启后都会更换访问码，需要刷新网页并输入新码。访问码只保存在程序和当前页面的内存中，不写入浏览器存储。

## 5. 导入和维护知识库

1. 点击主页顶部的 **本机知识库**，选择您自己要导入的文件。支持 `.docx`、文字型 `.pdf` 和 `.xlsx`，单个文件不超过 10 MiB。旧版 `.doc` 和 `.xls` 请先另存为 `.docx` 和 `.xlsx`；带密码的文件先由您自行解密。扫描图片型 PDF 没有可提取文字时不会被识别为文字，当前没有 OCR。
   为避免文件过大导致程序无响应，PDF 最多 200 页；Excel 最多 32 个工作表、每表 1 万行和 512 列，合计最多 10 万个单元格；文档提取文字及片段数量也有限制。超出限制时请拆分文件后导入。
2. 程序按需在 `D:\示范线知识库` 下创建自己的子目录，存放文件副本和可检索的文本索引；不会自动扫描其他硬盘，也不修改您选择的原始文件。如果 D 盘不存在或不可访问，请先检查磁盘与权限。
3. 管理面板列出已导入文件和索引状态。文件被修改后不会自动同步，请删除旧副本并重新导入。删除操作只针对本程序创建的副本和索引，不删除原始文件。普通删除并不保证数据无法被磁盘恢复。
4. 在右下角提问，程序首先检索本机知识库。找到内容时直接显示原文与文件名、页码、段落或工作表行号，不调用外部模型。Excel 摘录中的 `A4：`、`D4：` 等是附加的单元格坐标，帮助区分各列，不属于单元格原文。同名文件可用界面展示的完整标识区分。检索是基于文本的匹配，不保证涵盖同义表达或完整上下文，请通过文件管理器打开您保存的原始文件核实。
5. 如果没有匹配，或者本机知识库不可用，界面会先提示。选择 **不发送** 即不调用模型；只有点击 **同意发送本次问题**，才向已配置服务发送当前问题和固定系统提示，不附带本机文件、摘录或其他对话。问题本身如果包含敏感内容，也会被发送；请先检查问题。外部模型生成内容应自行核实，现场操作以企业规定为准。

为遵守上述隐私模式，外部模型看不到之前的问答，追问时请在当前问题中补充必要背景，并避免填写敏感信息。原先的公开知识资料仍保留在程序代码中，但本版聊天不会自动将其作为模型上下文或生成带这些资料来源的回答；本机命中时展示的是本机原文。

## 6. 隐私与备份注意事项

知识库副本和提取索引保存在 D 盘，**不是加密保险箱**。请为 Windows 账号、D 盘和备份设置合适的访问权限，必要时使用设备/磁盘加密。能够登录这台电脑的其他人、恶意软件、浏览器扩展、屏幕共享软件或企业备份软件仍可能接触数据。新版对话和摘录只放在页面运行内存中，不主动写入浏览器会话存储；刷新或关闭页面会清空对话。请避免在他人可用的会话中处理敏感资料。

本机访问码可阻止不知道访问码的其他本机进程直接调用接口，但不能防范同一 Windows 账户下的恶意程序、管理员、浏览器扩展或能看到启动窗口的人。请让 Windows 管理员在“文件属性 → 安全”中检查 `D:\示范线知识库` 和其 `assistant-data` 子目录，避免不可信账户获得写入、删除或重命名权限；同时审核父目录对该文件夹的删除或替换权限。目录检查不能完全抵御有权限的恶意程序在操作过程中替换链接。不要自行修改整个 D 盘的权限，以免影响其他工作；权限不明确时请咨询企业 IT 管理员。

本机访问码不保护云端公开部署：云端问答接口仍缺少企业级身份认证和限流，其他人可能直接调用并消耗模型额度，也能绕过网页上的同意按钮。云端无法读取您本机 D 盘；如要公开部署，应由管理员先增加服务端鉴权、限流和审计，且不要在云端页面处理敏感资料。

请自行备份 `D:\示范线知识库`。软件不会访问该目录之外的磁盘来自动扫描文档，也不会自动备份或云同步；如果您自己启用了系统级或第三方备份、同步软件，请按照其设置管理相关数据。未连接现场传感器时，助手不会获得实际读数或执行控制。
